# like-bot-v2

네이버 블로그 답방 유도 도구. 내 블로그 계정으로 관심 있는 주제의 최신 글에 공감을
누르면, 그 블로그 주인이 방문 기록을 보고 내 블로그를 찾아온다 — 이 왕복이 이 도구의
전부다. 자세한 배경과 설계 근거는 [CLAUDE.md](CLAUDE.md)에 있다.

## 내려받기

**[릴리스에서 `like-bot-v2-v0.1.0-win64.zip` 받기](https://github.com/embed-Rayn/like-bot-v2/releases/latest)**
(Windows 64비트)

압축을 풀고 `like-bot-v2.exe`를 실행한다. 파이썬도, 크롬도 따로 설치하지 않는다 —
브라우저까지 안에 들어 있다. 압축 해제 후 약 645MB.

> 처음 실행할 때 Windows SmartScreen이 "Windows의 PC 보호"를 띄운다. 서명하지 않은
> exe라서 그렇다. **추가 정보 → 실행**으로 넘어간다.

## 쓰는 법

1. **아이디 / 비밀번호** — 내 블로그 계정 하나만 쓴다. 여러 계정에 나눠 누르면 답방이
   여러 블로그로 흩어져서 목적 자체가 사라진다. 비밀번호는 Windows 자격증명 저장소
   (keyring)에만 들어가고 저장소나 파일에는 남지 않는다.
2. **키워드** — 내 블로그 주제와 겹치는 말로. 답방 확률이 여기서 갈린다.
3. **기간** — 최근으로 좁힐수록 "지금 활동 중인" 블로거가 걸린다.
4. **방문 상한 / 블로그당 공감 수** — 많은 블로그에 조금씩이 적은 블로그에 많이보다
   답방이 잘 나오고, 스팸으로도 덜 보인다.
5. **드라이런에 체크하고 한 번 돌려 본다.** 공감 버튼을 찾기만 하고 누르지는 않는다.
6. 그다음 방문 상한 3, 블로그당 공감 1로 작게 한 번. 그 뒤에 늘린다.

### 로그인

세션이 살아 있으면 로그인 화면을 아예 거치지 않는다. 세션이 없으면 아이디·비밀번호를
자동 입력하는데, 네이버가 "보안을 위해 추가 확인"을 띄우면 **브라우저 창을 열어 둔 채
기다린다.** 직접 확인을 끝내면 하던 일을 이어서 한다 (5분까지 기다림). 이 화면을
우회하려 들지 않는다 — 계정이 정지되면 답방이 0이 된다.

## 알아 둘 것

- **계정 안전이 속도보다 우선이다.** 분당 공감 수를 올릴수록 위험이 올라간다. 정지된
  계정은 트래픽을 한 명도 못 데려온다.
- **저장된 세션은 자격증명이다.** `%LOCALAPPDATA%\like-bot-v2\sessions\{계정}.dat`에
  로그인 쿠키가 들어 있다. 이 파일을 가진 사람은 비밀번호 없이 로그인된 상태가 된다.
  로그·스크린샷·화면 공유에 노출됐다면 네이버에서 **로그아웃(기기 관리)** 해서 폐기해야
  한다. 파일만 지우는 것으로는 무효화되지 않는다.
- **실행할 때마다 기록이 남는다.** `%LOCALAPPDATA%\like-bot-v2\logs\` 안에 실행 하나가
  파일 하나(`run-…jsonl`)다. 무언가 이상하면 창의 **📁 로그 폴더** 버튼을 눌러 그 실행
  파일을 열어 보거나 그대로 보내면 된다. 최근 30개만 남고 오래된 것은 알아서 지워진다.
  단, 이 파일에도 오류 메시지가 그대로 들어가니 세션·비밀번호가 찍혀 있지 않은지 보고
  공유할 것.
- 방문 기록은 계정별로 남는다. 상한 N은 "이 계정이 아직 안 가 본 블로그 N개"를 뜻한다.

## 개발

```
python -m pip install -e ".[dev]"
python -m pytest -q                      # 단위 테스트 (네트워크·브라우저 없음)
python -m pytest -q -m contract          # 실제 네이버, 비로그인
python -m pytest -q -m browser           # playwright install chromium 필요
python -m desktop.app                    # 앱 실행
```

exe 빌드는 [CLAUDE.md의 Packaging 절](CLAUDE.md#packaging-windows-exe)을 볼 것.
